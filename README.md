# 🎴 Dixit Tracker

Tracker de colección de mazos Dixit en HTML/CSS/JavaScript puro.

## ✨ Características

- 📊 15 mazos Dixit (bases + expansiones + especiales)
- 🖼️ Imágenes reales de cajas
- 💾 Guardado automático en localStorage
- 🔗 Compartir colección por URL
- 📱 Responsive (celular y desktop)
- ⚡ Sin dependencias, sin compilación
- 🚀 Funciona directamente en GitHub Pages

## 🚀 Cómo Publicar en GitHub Pages

### 1️⃣ Crear repo en GitHub
- https://github.com/new
- Name: `dixit-tracker`
- Public ✓
- Create

### 2️⃣ Hacer push
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/TU_USER/dixit-tracker.git
git branch -M main
git push -u origin main
```

### 3️⃣ Habilitar GitHub Pages
- Repo → Settings → Pages
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)
- Save

### 4️⃣ ¡Listo!
Tu sitio estará en: `https://tu-usuario.github.io/dixit-tracker/`

## 📝 Uso

- **Marcar mazo:** Click en la tarjeta
- **Compartir:** Click en botón "Compartir"
- **Limpiar:** Click en "Limpiar selección"
